## 2. RAG 是 Retrieval-Augmented Generation 的缩写，中文叫检索增强生成。它的核心思想是让大模型在生成答案时，先从一个外部知识库中检索相关信息，再基于这些信息回答问题。

我把 RAG 分为两个阶段来理解：

离线索引阶段：将私有知识库的文档进行切块、向量化，存入向量数据库；

在线查询阶段：将用户问题向量化，从向量数据库中检索最相关的 Top-K 文本块，拼接成 Prompt 后调用 LLM 生成答案。

相比微调，RAG 的优势是知识更新成本低、可溯源、幻觉少。
